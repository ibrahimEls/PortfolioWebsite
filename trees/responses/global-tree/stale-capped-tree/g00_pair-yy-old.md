# Reasoning

## Setup common to both leaves

The two sibling leaves share the same path prefix — a neutrino flux 1–10× IceCube-Gen2, a Galactic-centre (GC) continuum 10–100× the CTA WW sensitivity — and differ only in DARWIN (yes/no). Each contains one dominant **complex scalar doublet** unit (R0, inert-doublet-like: MDM ≈ 552–616 GeV, quartics ≤ 0.07 controlling the charged–neutral splitting, so a charged partner η± lies within ~0.35–2 GeV of the DM) plus a swarm of **complex scalar singlet + dark U(1)′** units (gU1p ≈ 0.29–0.51, MZp ≈ 1–580 GeV, kinetic mixing ε ≈ 10⁻⁶–10⁻¹). The Z2 vs Z2+3+4+5 labels pool byte-identical builds; the extra si·sr³-type terms only reshuffle dark self-couplings, so no external measurement can target the Z_N label itself — only the parameter regions.

The decisive structural difference: the doublet's annihilation to WW proceeds through EW gauge couplings with the **charged partner η± in the loop**, which unavoidably produces monochromatic γγ and γZ lines at E ≈ MDM; the singlets annihilate dominantly to Z′Z′ (α_D = g′²/4π ≈ 0.007–0.02 dwarfs any α1 ≤ 0.05 portal channel) and possess **no charged BSM state**, so their line-to-continuum ratio is ≲10⁻⁵ (only ε²-suppressed Z′–γ loop mixing or SM loops off the portal).

## Leaf `root_yes_yes_yes` (2925 pts, 26 units)

**Lit review — GC γ-ray line search (H.E.S.S.-type, CTA projection).** This is *not* a catalog observable: the catalog carries continuum channel limits (CTA WW/bb, Fermi WW/bb) and the IceCube-Gen2 ν flux; a monochromatic line search is a separately published measurement with its own analysis (arXiv:1805.05741 for the completed H.E.S.S. 10-year search; arXiv:2007.16129 for CTA GC sensitivity). Quantitatively: the path fixes σv(WW-like continuum) ≈ 10–100× the CTA GC sensitivity (~3×10⁻²⁶ cm³/s at 600 GeV), i.e. σv_cont ≈ 3×10⁻²⁵–3×10⁻²⁴ cm³/s. Every singlet unit predicts σv(γγ) ≲ 10⁻²⁹ cm³/s (line/continuum ≲ 10⁻⁵ of a Z′Z′-dominated total): invisible. Cut in absolute units: a line at 540–620 GeV with σv_γγ ≥ 3×10⁻²⁸ cm³/s. YES → R0; NO → all 25 singlet units. This is a Lagrangian-class separation, the highest-value kind.

**Novel — CTA spectral-endpoint spectroscopy for the singlet block.** The source is 10–100× above CTA sensitivity, i.e. O(10³–10⁴) signal photons: the *shape* is measurable, not just the flux.
